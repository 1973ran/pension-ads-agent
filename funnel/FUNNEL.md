# משפך שיווקי: ייעוץ פנסיוני (רן פיננסים)

## מבנה המשפך

```
מודעה בפייסבוק/אינסטגרם (3 זוויות)
        ↓
דף נחיתה: funnel/index.html
  Hook → מחשבון דמי ניהול (מגנט לידים) → כאב → פתרון → שאלון 5 שלבים
        ↓  (Lead)
דף תודה: funnel/thank-you.html → וואטסאפ / קביעת שיחה ביומן
        ↓
רצף פולואפ בוואטסאפ (7 ימים) → שיחת ייעוץ → לקוח
        ↑
רימרקטינג לכל מי שלא השאיר פרטים
```

| שלב | מטרה | נכס | אירוע פיקסל |
|---|---|---|---|
| TOFU: מודעות | עצירת גלילה | מודעות וידאו/קרוסלה | PageView |
| MOFU: מעורבות | מגנט לידים | מחשבון דמי ניהול | ViewContent |
| התחלת המרה | מחויבות קטנה | שאלה ראשונה בשאלון | InitiateCheckout |
| BOFU: המרה | ליד | שם, טלפון והסכמה ליצירת קשר | Lead |
| אחרי הליד | פגישה | דף תודה + וואטסאפ | CompleteRegistration |

## הקמה (15 דקות)

1. לערוך את `funnel/config.js`: מספר וואטסאפ, טלפון, מספר רישיון, Pixel ID, Webhook ו-Calendly.
2. Webhook ללידים: Make/Zapier, או Google Apps Script שכותב ל-Google Sheets. ה-POST שולח JSON עם שם, טלפון, תשובות השאלון, ההפסד המשוער ופרמטרי UTM. בלי Webhook הליד נפתח ישירות בוואטסאפ.
3. להעלות את תיקיית `funnel/` לאתר (לדוגמה `ranmessika.com/check/`) או ל-Netlify/Vercel.
4. ב-Ads Manager: להגדיר אופטימיזציה לאירוע **Lead**.
5. להוסיף UTM לכל מודעה: `?utm_source=fb&utm_campaign=fees&utm_content=video1`

## מודעות: 3 זוויות לבדיקה (A/B)

**זווית 1: כסף שהולך לאיבוד (דמי ניהול)**
> הפרש של חצי אחוז בדמי הניהול יכול להגיע למאות אלפי שקלים עד הפרישה 😳
> רוב השכירים חתמו על דמי ניהול לפני שנים ומאז אף אחד לא בדק.
> 👈 בדקו בחינם, תוך דקה, כמה זה אצלכם.

כותרת: *כמה הפנסיה שלך מפסידה?*  |  CTA: מידע נוסף

**זווית 2: "לא יודע מה יש לי"**
> 3 קופות מעבודות קודמות? ביטוח שאולי משולם פעמיים?
> בבדיקה אחת דרך המסלקה הפנסיונית רואים הכול במקום אחד.
> 👈 בדיקת פנסיה אישית ללא עלות.

כותרת: *כל הפנסיה שלך, במקום אחד*

**זווית 3: לקראת פרישה (55+)**
> 10 השנים שלפני הפרישה הן הקריטיות ביותר.
> קיבוע זכויות, מסלול השקעה, משיכה הונית או קצבה: החלטות שאי אפשר לתקן אחרי.
> 👈 שיחת תכנון פרישה ראשונית ללא עלות.

כותרת: *מתכננים פרישה? אל תנחשו*

**קריאייטיב מומלץ:** וידאו סלפי של 20–30 שניות (רן מדבר למצלמה עם טיפ אחד), צילום מסך מטושטש של דוח שנתי עם עיגול על דמי הניהול, קרוסלה "5 טעויות בפנסיה".

## קהלים ותקציב

| קמפיין | קהל | תקציב יומי |
|---|---|---|
| Prospecting: זווית 1+2 | ישראל, 28–55, Advantage+ (בלי טרגוט צר) | ₪60–100 |
| Prospecting: זווית 3 | ישראל, 52–64 | ₪30–50 |
| Retargeting | ביקרו בדף / השתמשו במחשבון ולא השאירו פרטים (14 יום) | ₪20–30 |

**מודעות רימרקטינג:**
- "חישבת כמה את/ה מפסיד/ה, עכשיו בוא/י נבדוק את המספר האמיתי" (למי שהשתמש במחשבון)
- שאלות נפוצות: "זה עולה כסף? זה מחייב לעבור חברה?" (ההתנגדויות מה-FAQ)
- המלצת לקוח אמיתית, בווידאו או בטקסט

כלל עצירה: מודעה עם יותר מ-₪150 הוצאה ו-0 לידים, או CPL גבוה פי 2 מהממוצע אחרי 3 ימים, נכבית.

## רצף פולואפ בוואטסאפ

| מתי | הודעה |
|---|---|
| דקות ספורות אחרי הליד | היי {שם}, כאן רן מ"רן פיננסים" 👋 קיבלתי את הפרטים לבדיקת הפנסיה. מתי נוח לך לשיחה קצרה של 10 דקות, היום או מחר? |
| +1 יום (אם אין מענה) | {שם}, רק מזכיר: הבדיקה לוקחת דקות ספורות ובלי שום התחייבות. לשלוח קישור לייפוי כוח דיגיטלי למסלקה כדי שאגיע מוכן לשיחה? |
| +3 ימים | טיפ קצר: בדוח השנתי מופיעים שני סוגי דמי ניהול, מהצבירה ומההפקדה. שווה להציץ ולבדוק את שניהם. רוצה שנעבור על זה יחד? |
| +7 ימים | אני סוגר את רשימת הבדיקות לשבוע. להשאיר לך מקום, או שנחזור לזה בהמשך? |

לשקף זמני תגובה: ליד שמקבל מענה תוך 5 דקות נסגר בהרבה יותר סבירות מליד שמחכה שעות. מומלץ לחבר את ה-Webhook להתראה מיידית לנייד.

## מדדים ויעדים (נקודת פתיחה, לכייל אחרי שבועיים)

| מדד | יעד ראשוני |
|---|---|
| CTR קישור | ≥ 1.2% |
| שימוש במחשבון / ביקורים | ≥ 25% |
| התחלת שאלון / ביקורים | ≥ 20% |
| המרה לליד / ביקורים | 8–15% |
| CPL | לפי הנתונים בפועל, ובהשוואה לקמפיינים קיימים |
| ליד → שיחה שהתקיימה | ≥ 40% |
| שיחה → לקוח | ≥ 25% |

## ציות ורגולציה

- ניסוח המחשבון מוצג כ"הערכה בלבד" וללא הבטחת תשואה. כך גם צריך להיות בכל מודעה.
- להציג את מספר רישיון יועץ פנסיוני (שדה `licenseNumber`).
- המלצות: רק אמיתיות ובאישור הלקוח (שדה `testimonials`; ריק = הסקשן מוסתר).
- הסכמה מפורשת ליצירת קשר מובנית בטופס. לדיוור שיווקי צריך הסכמה נפרדת (חוק התקשורת, סעיף 30א).
