# סוכן הפרסום הפנסיוני ב-WhatsApp 💬

שרת קטן שמחבר את הסוכן ל-WhatsApp: שולחים לו הודעה מהטלפון, והוא עונה עם פוסטים, ברייפים לקמפיינים, ניתוחי ביצועים ורעיונות לתוכן, בדיוק כמו בממשק `facebook-agent.html`.

```
הטלפון שלך ──► WhatsApp Cloud API (Meta) ──► השרת הזה (/webhook) ──► Claude
            ◄──────────────────────────────── תשובה ◄──────────────────┘
```

## מה אפשר לכתוב לו

| הודעה | מה קורה |
|---|---|
| `פוסט קרן השתלמות לעצמאים` | פוסט לפייסבוק + האשטגים |
| `קמפיין לידים, 50 ש"ח ליום, שכירים 30-55` | ברייף מלא לקמפיין ממומן |
| `ניתוח הגעה 12,400, לידים 34, עלות לליד 67` | 4-5 המלצות לשיפור |
| `רעיונות ביטוח מנהלים` | 10 רעיונות לפוסטים |
| `איפוס` | שיחה חדשה (הסוכן זוכר את 10 ההודעות האחרונות) |
| `עזרה` | תפריט |
| כל טקסט חופשי | שיחה רגילה עם הסוכן, למשל "תקצר את הפוסט" או "תכתוב גרסה יותר דחופה" |

## הקמה (פעם אחת)

### 1. אפליקציה ב-Meta
1. היכנס ל-[developers.facebook.com](https://developers.facebook.com) → **Create App** → סוג **Business** → הוסף את המוצר **WhatsApp**.
2. בעמוד **WhatsApp → API Setup** תקבל:
   - **Phone number ID** → `WHATSAPP_PHONE_NUMBER_ID`
   - **Temporary access token** (תקף ל-24 שעות, מתאים לבדיקה). לשימוש קבוע צור **System User** ב-Business Settings עם הרשאת `whatsapp_business_messaging` והפק טוקן קבוע → `WHATSAPP_TOKEN`
3. באותו עמוד הוסף את המספר האישי שלך לרשימת **To** (במצב בדיקה אפשר לשלוח רק למספרים שאישרת).
4. ב-**App Settings → Basic** העתק את **App Secret** → `WHATSAPP_APP_SECRET`.

### 2. הרצת השרת
```bash
cd whatsapp-bot
npm install
cp .env.example .env   # ומלא את הערכים
npm start
```
`ALLOWED_NUMBERS` הוא המספר שלך בפורמט בינלאומי בלי `+` ובלי `0`: 050-1234567 נכתב `972501234567`. הודעות מכל מספר אחר לא ייענו, כך שאף אחד אחר לא ישתמש בסוכן על חשבונך.

השרת צריך כתובת HTTPS ציבורית:
- **לבדיקה מהמחשב:** `npx ngrok http 3000` (או `cloudflared tunnel --url http://localhost:3000`) ותקבל כתובת כמו `https://abcd.ngrok-free.app`.
- **לשימוש קבוע:** Render, Railway או Fly.io. מעלים את התיקייה, פקודת ההרצה היא `npm start`, ואת המשתנים מה-`.env` מגדירים בהגדרות השירות.

### 3. חיבור ה-Webhook
ב-Meta: **WhatsApp → Configuration → Webhook → Edit**
- **Callback URL:** `https://<הכתובת-שלך>/webhook`
- **Verify token:** אותו ערך שהגדרת ב-`WHATSAPP_VERIFY_TOKEN`
- אחרי האימות לחץ **Manage** והירשם לשדה **messages**.

זהו. שלח "עזרה" למספר ה-WhatsApp של האפליקציה.

## הערות
- **היסטוריית השיחה נשמרת בזיכרון** ומתאפסת בכל הפעלה מחדש של השרת.
- **חלון 24 שעות:** WhatsApp מאפשר לעסק לשלוח הודעה חופשית רק בתוך 24 שעות מההודעה האחרונה שלך. הבוט רק עונה להודעות, אז זה לא מגביל אותו. שיחות שירות שאתה פותח הן בחינם במסגרת המכסה של Meta.
- **המודל:** ברירת המחדל היא `claude-opus-5`. אפשר להחליף עם `CLAUDE_MODEL` (למשל `claude-sonnet-5`, זול יותר).
- **מדיניות Meta:** מאז ינואר 2026 אסור להפעיל ב-WhatsApp Business צ'אטבוט AI כללי. הבוט הזה ממוקד (עוזר שיווק לעסק שלך) ופתוח רק למספרים שהגדרת, כך שהוא בגדר השימוש המותר.
- **אבטחה:** כל בקשה נכנסת נבדקת מול חתימת `X-Hub-Signature-256`, כך שרק Meta יכולה לשלוח לשרת הודעות.
